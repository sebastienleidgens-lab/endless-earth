Voir [le rapport de révision](../living-paintings-visual-upgrade.md). Les captures sont issues du vrai jeu dans Chromium, sans photomontage. Les textures WebP de `public/` sont des rendus précalculés, distincts de ces captures du navigateur.

La promenade complète utilise la boucle réelle du jeu, à vitesse normale, sans déplacement injecté ni accélération du temps. Les contrôles mobiles restent des émulations, sans appareil physique. Les détails de façade et les arches du pont sont une reconstruction artistique, pas un relevé du lieu. La validation esthétique appartient au propriétaire.
