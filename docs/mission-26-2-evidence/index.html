Performance : les limites restent visibles

Bancs sans encodeur, trois profils avec effets et audio actifs, framebuffer imposé identiquement. Machine distante sans /dev/dri, Chromium SwiftShader. Échantillons de 20 secondes : P99 incertain ; aucun résultat matériel 60/30 FPS ni borne de non-régression ≤5 % validé. Les cas sans mesure restent des échecs.
