# Prepared pedestrian graph

Derivative of the existing IGN terrain / structures (Licence Ouverte 2.0) and
© OpenStreetMap contributors (ODbL 1.0). This derived geographic database is
provided under ODbL 1.0, retaining IGN attribution and terms.

The graph is the exact existing buildGraph algorithm output after source-bound
physical validation in the real game. It does not document new access rights,
repair OSM connectivity, infer crossings or authorize an inaccessible bridge.
Runtime movement still uses the same capsule, terrain and access checks.
See the source bindings and generator hashes in angles-walk-graph.json.
